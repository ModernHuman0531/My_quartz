## 機場到宿舍交通
大致路線：**神戶機場**  
↓ Port Liner  
**三宮駅**  
↓ 步行轉乘  
**神戸三宮駅（阪急）**  
↓ 阪急神戸線  
**十三駅**  
↓ 阪急京都線  
**淡路駅**  
↓ 阪急千里線  
**山田駅**  
↓ 步行約 6–15 分鐘  
**大阪大学 津雲台国際学生宿舎**
### 詳細路線
1. 神戶機場->三宮
	1. 下飛機、入境、領行李之後，跟著『ポートライナー / Port Liner』指標走，神戶機場的 Port Liner 車站就在航廈旁，而且與機場航廈的交通非常方便。神戶機場官方資料指出，Port Liner 從神戶機場到三宮約 **18分鐘**。
	2. 起點：神戸空港駅（P09），搭『ポートライナー 三宮方面』沿途大致：神戸空港  → 計算科学センター  → 医療センター  → 市民広場  → みなとじま  → 中公園  → 貿易センター  → **三宮**
2. 三宮 → 阪急「神戸三宮」
	1. 到了 **三宮駅** 後，不要去搭 JR。你要找：> **阪急電車 / Hankyu**然後前往：> **神戸三宮駅**這兩個地方距離不遠，跟著「阪急電車」的標誌走即可。你的下一段是：**阪急 神戸三宮 → 十三**
3. 神戸三宮 → 十三
	1. 到了阪急神戶三宮站後，搭：『 **阪急神戸本線**』方向：**大阪梅田方面**最重要的是：不要在大阪梅田下車你要在：**十三（じゅうそう / Jūsō）**下車。也就是：**神戸三宮**  -> 春日野道  ->  六甲  ->  岡本  ->  西宮北口  ->  ……  ->  **十三**這段大約 **25分鐘左右**。
4. 十三 → 淡路
	1. 到了 **十三駅** 後，你要轉：『阪急京都線』，方向為『京都河原町 / 北千里』，目的地為『淡路（あわじ / Awaji）』，但十三不是最終轉車站，只是在十三從『神戶線』到『京都線』，然後十三->淡路，路線為：神戸三宮 → 十三 → 淡路 → 山田
5. 淡路 → 山田
	1. 到了 **淡路駅**，這是最後一次轉車。找『阪急千里線』，方向為『北千里方向』搭到『山田』，途中行經：淡路->下新庄->吹田->豐津->関大前->千里山->南千里->山田
6. 山田站 → 津雲台宿舍
	1. 罪後步行到津雲台宿舍即可

### 台灣郵局(或銀行)該如何匯錢到日本的郵局銀行
*   到那邊應該怎麼跟他們講(要去的窗口是**貯金窓口**)
```
すみません。  
ゆうちょ銀行の口座を開設したいです。

大阪大学の留学生です。

留学中の生活費のためです。
```

*  因為你不是單純開一個日本銀行帳戶，而是已經知道自己未滿 6 個月，未來要有跨境資金
```
私は9月16日に日本に入国したばかりで、まだ6か月経っていません。

台湾にある自分名義(めいぎ)の口座から、留学中の生活費をWise経由(けいゆ)で自分のゆうちょ口座に送金(そうきん)したいです。

この口座で受け取ることはできますか？

台湾にある自分名義の口座から送金します。

母から生活費として受け取っています。

Wiseという海外送金サービスを使って、台湾の自分名義の口座から日本の自分の口座に生活費を送金する予定です。

この口座に海外から送金する場合、必要な口座情報を教えていただけますか？
Wiseから送金する予定です。
```
