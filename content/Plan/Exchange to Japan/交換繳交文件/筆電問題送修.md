# 筆電問題送修
到日本後，我的筆電(MSI Cybrog 15 A12V)筆電的風扇無法順利開啟，導致CPU溫度過高，所以時不時會自動關機，因此我要在日本找到可以維修的店，並順利的傳達我的筆電的問題，還有詢問到底什麼時候可以拿回來(現場拿不用寄送)

## 維修店
* ヨドバシカメラ マルチメディア梅田
	* 阪急駅　地下1階～地上4階のパソコン専門フロア

## 言い方
一開始先說：
```
すみません、MSIのノートパソコンの修理について相談したいです。

MSI Cyborg 15 A12Vを使っていますが、ファンがまったく回らなくなりました。

MSI公式の修理受付をお願いしたいのですが、こちらで対応(たいおう)できますでしょうか？
```
店員如果說可以，再把手機上的這段給他看：
```
症状について説明します。

・WindowsのMSI Centerではファン回転数が0 RPMです。  
・Fn + ↑でCooler Boostを有効(ゆうこう)にしてもファンが回りません。  
・MSI CenterでCooler Boostを有効にしても回りません。  
・ECリセットを実施(じっし)しましたが改善(かいぜん)しませんでした。  
・BIOS画面でもファンがまったく回りません。

Windows使用中はCPUが約78℃、GPUが約76℃まで上がりました。

そのため、単なる(たんなる)WindowsやMSI Centerの問題ではなく、ファン本体、ファンケーブル、EC、またはマザーボード側に問題がないか確認していただきたいです。

保証期間外ですが、できればMSI純正部品(じゅんせいぶひん)を使用したメーカー修理を希望しています。
```
